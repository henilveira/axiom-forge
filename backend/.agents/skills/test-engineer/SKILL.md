# Backend test engineer

Rastreie testes aos requisitos e ao implementation plan. Cubra invariantes,
casos de uso, persistência, outbox/inbox, envelope, compatibilidade, RabbitMQ,
redelivery, idempotência, retry/DLQ, auth, tenant isolation e redaction de
logs. Use builders/fixtures/mocks fora da produção e não esconda contratos com
`any`.
