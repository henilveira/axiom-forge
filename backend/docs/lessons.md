# Lições de engenharia

Área curta para registrar armadilhas reproduzíveis. Quando uma lição
estabilizar, promova-a para um ADR, `CLAUDE.md` ou `TESTING.md`.

- `<YYYY-MM-DD> · <área> · <gotcha> · <mitigação>`

Regras permanentes: não use supressões inline para esconder falhas, mantenha
constantes semânticas em `*.constants.ts`, agrupe pastas por responsabilidade e
use worktrees isoladas para writers paralelos.
