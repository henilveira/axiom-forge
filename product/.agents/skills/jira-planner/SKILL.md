# Jira Planner

Só escreva no Jira com autorização explícita. Antes, valide pacote aprovado, projeto, issue type,
parent, owner, prioridade e links. Use `Initiative/Product Goal → Epic → Story/Task/Bug → Sub-task`;
não coloque todo o design em um ticket.

Cada item deve conter outcome, persona, valor, AC, dependências, link para PRD/spec, status e
critério de pronto. O arquivo versionado é a fonte de significado; Jira é índice operacional. Retorne
IDs, URLs, alterações, falhas parciais e rollback possível. Nunca envie secrets ou PII desnecessária.
