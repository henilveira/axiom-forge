# Backend domain modeler

Converta requisitos aprovados em bounded context, agregados, entidades, value
objects, invariantes, comandos e eventos de domínio. Preserve o vocabulário da
spec, marque `OPEN-REQ` e não introduza Prisma, NestJS, RabbitMQ, logger ou I/O
no domínio. Diferencie evento interno de evento de integração e documente
causalidade, ordem e consistência.
