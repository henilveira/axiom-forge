# Biblioteca de engenharia Backend

Fontes de consulta; decisões locais continuam normativas nos documentos e ADRs
deste repositório.

- [NestJS RabbitMQ transporter](https://docs.nestjs.com/microservices/rabbitmq) — integração Nest com RMQ.
- [RabbitMQ publisher confirms](https://www.rabbitmq.com/docs/confirms) — confirmação de publicação e ack.
- [RabbitMQ reliability](https://www.rabbitmq.com/docs/reliability) — durabilidade e falhas.
- [RabbitMQ DLX](https://www.rabbitmq.com/docs/dlx) — dead-letter exchanges.
- [RabbitMQ quorum queues](https://www.rabbitmq.com/docs/quorum-queues) — filas duráveis.
- [Transactional Outbox](https://microservices.io/patterns/data/transactional-outbox.html) — evitar dual-write.
- [Idempotent Consumer](https://microservices.io/patterns/communication-style/idempotent-consumer.html) — at-least-once.
- [OpenTelemetry](https://opentelemetry.io/docs/) — traces, métricas e contexto de correlação.
- [Prisma transactions](https://www.prisma.io/docs/orm/prisma-client/queries/transactions) — transação e consistência.
