# Registro de fontes metodológicas

Esta biblioteca usa referências públicas para orientar processo, não para
substituir decisões do negócio. A decisão local sempre precisa de fonte,
confiança, owner e data.

- [Scrum Guide 2020](https://scrumguides.org/scrum-guide.html) — accountability do Product Owner e transparência do Product Backlog.
- [Atlassian PRD](https://www.atlassian.com/agile/product-management/requirements) — estrutura colaborativa e evolutiva de PRD.
- [GOV.UK discovery](https://www.gov.uk/service-manual/agile-delivery/how-the-discovery-phase-works) — descoberta antes de delivery.
- [GOV.UK user research](https://www.gov.uk/service-manual/user-research/user-research-in-discovery) — pesquisa com perguntas e evidências.
- [NN/G personas](https://www.nngroup.com/articles/why-personas-fail/) — persona como síntese de pesquisa, não estereótipo.
- [Product Talk opportunity solution tree](https://www.producttalk.org/opportunity-solution-trees/) — outcome, oportunidade, solução e testes de hipótese.
- [Agile Alliance/BABOK](https://www.agilealliance.org/wp-content/uploads/2017/08/AgileExtension_V2-Member-Copy.pdf) — análise ágil e critérios de histórias.
