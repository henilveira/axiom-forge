# Biblioteca de Referência

Esta pasta é intencionalmente vazia de regras de negócio. Use-a para registrar,
com status e fontes, apenas o contexto do produto que será criado.

## Pastas preparadas

- `personas/` — hipóteses de pessoas e contextos de uso.
- `journeys/` — jornadas ponta a ponta.
- `hypotheses/` — teses e contra-hipóteses.

Comece pelos templates em `../_templates/`. Nenhum arquivo desta biblioteca
autoriza runtime sem uma spec aprovada em `../../specs/`.
