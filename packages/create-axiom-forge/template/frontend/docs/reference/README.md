# Referências externas consumidas pelo Frontend

O Frontend pode consultar duas fontes versionadas, sempre em commit fixado:

1. `../backend/docs/integration/` — contrato técnico aprovado;
2. uma referência visual read-only adicionada pelo projeto derivado, quando necessária.

Product (`../product`) não é dependência de runtime nem fonte de endpoints para o Frontend.
As referências devem ser citadas no plano da feature e não copiadas como
agentes ou código sem revisão.
