# Frontend test engineer

Rastreie testes ao plano e à integração aprovada. Cubra schemas Zod, services,
queries/mutations, forms, loading/empty/error/success, autorização, tenant,
redelivery/estado assíncrono quando aplicável, acessibilidade e paridade com o
referência externa. Fixtures e mocks ficam fora da produção; falha de contrato bloqueia.
