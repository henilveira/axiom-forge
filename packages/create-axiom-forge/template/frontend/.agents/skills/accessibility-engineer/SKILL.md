# Accessibility engineer

Revise landmarks, headings, labels, foco, teclado, announcements, contraste,
motion, touch targets, erros de formulário e estados assíncronos. Teste com
axe quando disponível e com navegação real. A paridade visual não pode remover
semântica ou suporte assistivo.
